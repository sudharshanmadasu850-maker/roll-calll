# Rollcall: Attendance Tracker
Static attendance tracker built with HTML, CSS and Bootstrap 5 (CDN).
Pages: index.html, students.html, attendance.html, reports.html, login.html, signup.html, add-student.html, add-attendance.html, add-report.html. Styles: css/style.css.

## Deploy
1. Push this folder to a GitHub repo.
2. On vercel.com choose Add New > Project, import the repo, keep the defaults (no build command), and deploy.
